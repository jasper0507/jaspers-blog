## 一、什么是 Internet

### 1 Internet 的组成（从结构角度）

Internet 可以看作是一个 **“网络的网络（Network of Networks）”**。 

其基本组成包括：

#### 1. 端系统（End Systems）

又称 **主机（Host）**：

* PC
* 手机
* 服务器
* IoT设备

特点：

* 运行各种网络应用
* 位于 **网络边缘（Network Edge）**

---

#### 2. 分组交换设备（Packet Switches）

负责 **转发数据包（packet）**

主要设备：

* **路由器（Router）**
* **交换机（Switch）**

功能：

* 根据 **目的地址** 决定数据包的下一跳

---

#### 3. 通信链路（Communication Links）

连接网络设备的传输媒介：

* 光纤
* 同轴电缆
* 双绞线
* 无线链路

关键指标：

```
带宽 Bandwidth
单位：bps (bit per second)
```

---

#### 4. ISP（Internet Service Provider）

互联网由 **多个 ISP 互联组成的层次结构**：

```
终端用户
   │
接入ISP
   │
区域ISP
   │
全球ISP
```

---

### 2 Internet 的另一种理解（从服务角度）

Internet 也可以理解为：

> **为分布式应用提供通信基础设施**

典型应用：

* Web
* Email
* 视频流
* 在线游戏
* 社交网络

通信通过 **套接字接口（Socket Interface）** 提供给应用。 

---

## 二、什么是协议（Protocol）

### 协议定义

协议是：

> **通信双方交换消息的格式、顺序以及在发送和接收消息时采取的动作规则**

协议规定：

1. 消息格式
2. 消息发送顺序
3. 收到消息后的处理动作

---

### 示例

人类协议：

```
A: What time is it?
B: 2:00
```

网络协议：

```
TCP Connection Request
TCP Connection Response
HTTP GET
HTTP Response
```

说明：

* **互联网所有通信都依赖协议**

常见协议：

| 层   | 协议                |
| --- | ----------------- |
| 应用层 | HTTP DNS FTP SMTP |
| 传输层 | TCP UDP           |
| 网络层 | IP                |
| 链路层 | Ethernet WiFi     |

---

## 三、网络边缘（Network Edge）

网络边缘主要包括：

### 1 主机（Hosts）

分为：

```
Client（客户端）
Server（服务器）
```

服务器通常部署在：

```
Data Center（数据中心）
```

运行应用：

* Web
* Email
* 数据服务

---

#### 2 接入网络（Access Network）

接入网络用于：

> 将端系统连接到 Internet

---

### 常见接入方式

#### 1 家庭接入

典型方式：

* Cable modem
* FTTH（光纤到户）

特点：

```
多个用户共享带宽
```

---

#### 2 企业网络

企业网络通常：

```
交换机 + 路由器
```

技术：

| 技术       | 速率                        |
| -------- | ------------------------- |
| Ethernet | 100Mbps / 1Gbps / 10Gbps  |
| WiFi     | 11Mbps / 54Mbps / 450Mbps |

---

#### 3 无线接入

两种主要类型：

##### WLAN

WiFi：

```
802.11b/g/n
速率：11Mbps~450Mbps
范围：几十米
```

---

##### 蜂窝网络

如：

```
4G / 5G
```

特点：

* 覆盖范围大
* 速率可达 **Gbps**

---

## 四、物理媒介（Physical Media）

数据在链路上传输的单位：

```
bit
```

物理链路分为两类：

---

### 1 有线媒介（Guided Media）

信号沿 **物理媒介传播**

#### 常见类型

##### 双绞线

特点：

```
两根铜线扭在一起
```

速率：

```
Cat5 : 100Mbps / 1Gbps
Cat6 : 10Gbps
```

---

##### 同轴电缆

特点：

* 两根同轴铜导线
* 支持宽带通信

多个信道：

```
每个信道100Mbps级别
```

---

##### 光纤

特点：

* 使用光信号
* 误码率低
* 不受电磁干扰

速率：

```
10Gbps ~ 100Gbps
```

---

### 2 无线媒介（Unguided Media）

使用 **电磁波传播信号**

类型：

* WiFi
* 蜂窝网络
* 蓝牙
* 卫星通信
* 微波通信

无线传播问题：

```
反射
干扰
遮挡
```

---

## 五、网络核心（Network Core）

网络核心是：

```
由大量路由器互联组成的网状结构
```

作用：

```
在源主机与目标主机之间转发数据
```

---

### 两种交换方式

#### 1 电路交换（Circuit Switching）

特点：

```
通信前需要建立连接
```

资源：

```
专用（独占）
```

典型例子：

```
传统电话网络
```

优点：

* 性能稳定

缺点：

```
资源利用率低
建立连接延迟
```

---

#### 2 分组交换（Packet Switching）

互联网使用的方式。

原理：

```
将数据拆分为多个 packet
逐跳转发
```

---

### 存储转发（Store-and-Forward）

发送流程：

```
Host → Router → Router → Destination
```

特点：

* 每一跳必须 **完整接收分组**
* 再转发

传输延迟：

```
L / R
```

其中：

```
L = 分组大小(bit)
R = 链路速率(bps)
```

---

## 六、分组交换核心功能

分组交换依赖两个核心机制：

---

### 1 转发（Forwarding）

本地操作：

```
根据转发表
决定数据包从哪个接口发出
```

---

### 2 路由（Routing）

全局操作：

```
计算从源到目的的路径
```

通过：

```
Routing Algorithm
```

---

## 七、分组交换 vs 电路交换

| 特性   | 电路交换 | 分组交换     |
| ---- | ---- | -------- |
| 资源   | 独占   | 共享       |
| 建立连接 | 需要   | 不需要      |
| 利用率  | 低    | 高        |
| 延迟   | 稳定   | 可能排队     |
| 适用   | 电话   | Internet |

结论：

```
分组交换更适合计算机网络
```

原因：

* 数据具有 **突发性**
* 可以共享带宽
