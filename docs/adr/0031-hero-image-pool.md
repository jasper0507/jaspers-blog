# 首页主视觉改为目录图池

首页主视觉不再维护亮暗成对照片。作者把 `.jpg` 放进 `public/images/hero/`，构建扫描该目录（不递归）入池；下架即删文件。合同：JPEG、扩展名只能是 `.jpg`、3:2（允许 1 像素误差）、至少 960×640。空目录、其它文件或不合格尺寸使构建失败。

亮暗主题共用这一池。首页每次整页刷新由浏览器在首屏前随机抽一张；无脚本时使用文件名排序后的第一张。主题切换不换图。

`blog.config.ts` 只保留 caption 与共用 alt。本决策撤回 ADR-0013 的亮/暗双图、ADR-0023 的 `lightImage` / `darkImage` 必填字段，以及 ADR-0027 中首页双图跟随 `data-theme` 的条款。
