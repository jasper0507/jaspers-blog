# 单篇页改为编辑排版，正文分层对齐 Kraft Paper

v2 收工前调整单篇技术文章页与少量外壳：废弃 ADR-0001 / ADR-0013 中「768px 纸张卡片 + 页边目录、非独立双栏」的合同，改为编辑长文版式；列宽与页眉/目录气质对齐 JacksBlog 文章页（以 `https://jackchou00.com/posts/photo-compress-beta/` 为参照），正文组件视觉以 `kraft-paper-v2`（及对应暗色）为唯一基准，但 **font-family 继续使用站点现有配置**。

## 版式

- **去卡片**：正文不再包在带明显边框/纸面底的白色大盒子里，直接进入主内容流。
- **阅读栏**：居中，最大宽度 **760px**（JacksBlog `--reading`）；外壳仍约 **1120px** 内容宽。
- **目录**：宽约 **180px**，`position: fixed`，位于阅读栏右侧外侧；仅视口 **≥1280px** 显示。无 h2/h3 条目时整块不渲染。滚动时高亮当前节（`aria-current`）。
- **标题区**：大标题 → 摘要 → 一行元信息；标题区与正文之间一条细分隔线。元信息**仅展示发布时间**，格式 `YYYY.MM.DD`，无「发布于」前缀，**页面不展示更新时间**（`updatedAt` 若仍存在于数据中，不用于该行 UI）。标签在元信息行弱化呈现（见下）。
- **字体**：站点既有衬线/无衬线/等宽角色不变；不采用「文章大标题改无衬线」的方案。

## 色板分层（选型 A）

全站外壳 token（背景、导航、页脚、标题区、目录、标签弱链所用的壳色）**保持现状**，不因正文主题整站换皮。

- 亮色/暗色外壳继续用现有 `--background` / `--text` / `--muted` 等。
- **仅 `.post-body`（正文组件）** 映射 Kraft Paper 亮色与暗色内容变量（字色、标题色、引用、行内码、代码块、表格线、强调色等）；可整理为内容层 CSS 变量，作用域限定文章正文，避免泄漏改首页。
- 去卡片后，文章页整页底仍为壳背景，不铺一层全页 Kraft `#faf9f5` 纸面带。

选型依据：首页与第二轮外壳已验收；正文要跟 Typora Kraft 主题一致，二者用分层比「全站改 kraft」或「文章区整页纸带」更稳。决策前用抛弃式原型 `/prototype/post-token-layers/?variant=A|B|C` 对照（A 胜出）。

## 标签呈现

- **挂在技术文章上的标签**（单篇页与归档时间轴）：统一为弱化 **`#tag` 文本链**，不再使用浅色 pill/小按钮。
- **`/tags/` 标签云**：保持现有 chip 卡索引，不改为 `#tag` 列表。

## 同批小改（#19 已落地）

非正文范式，但本轮收工一并做；子工单 **#19** 已实现并人工验收（`fb9d0ed`）：

- 顶栏品牌可见文案改为 **JaspersBlog**（仅顶栏；站点 `title`、页脚等本 ADR 不强制改名）。
- 首页内容不足一屏时消除多余纵向滚动。落地时确认外壳 `min-height: 100dvh` + flex sticky footer 本身不叠高；假滚来自 Pagefind `[data-pf-sr-hidden]` live region 在文档流末尾的 1×1 绝对定位盒撑高 `scrollHeight`，以钉 `top`/`left` 消除。验收落在 dist 与 visual 合同上。

## 编辑壳（#20 已落地）

子工单 **#20** 已实现并人工验收（`d2f732f`）。范围仅限**单篇技术文章页编辑壳**，不含正文组件换皮与标签弱链：

- **去卡片**：`.post-body` 不再铺独立纸面底与 inset 边框；整页底为壳背景。
- **阅读栏**：`--reading-width: 47.5rem`（约 760px）居中；外壳仍约 1120px。
- **标题区**：大标题 → 摘要 → 仅发布时间 `YYYY.MM.DD`（无「发布于/更新于」、不展示 `updatedAt`）→ 细分隔线 → 正文。标签形态见 **#21**（本票落地时曾暂留 pill）。
- **目录**：约 180px、`position: fixed`、位于阅读栏右侧外侧（`left ≈ calc(50% + reading/2 + 40px)`）；仅视口 **≥1280px** 显示；无 h2/h3 时不渲染；滚动以 `aria-current` 高亮当前节。
- **合同**：dist / visual 已从旧 768 卡片 / 704 净宽断言改为上述版式与目录规则。

## 标签弱链（#21 已落地）

子工单 **#21** 已实现并人工验收（`b4040de`）：挂在技术文章上的标签统一为弱化 `#tag` 文本链。

- **单篇页**：标签落在标题区元信息行（左时间、右 `#tag`），非 pill。
- **归档**时间轴：条目上的标签同为 `#tag` 文本链。
- **`/tags/` 标签云**：仍为 chip 卡（含计数），不改为 `#tag` 列表。
- 标签仍链到对应标签列表；键盘焦点走全站 `:focus-visible`。
- dist / visual 合同覆盖 `#tag` 形态、非 pill 样式，以及标签云仍为 chip。
- 部分取代 ADR-0013 中「单篇/归档上的 `.post-tags` 仍为轻量 pill」。

**仍留给后续子票**：

- 正文引用、表格、代码块、标题节奏等对齐 Kraft Paper → **#22**
- 公式上下标等 KaTeX 显示异常 → 随 **#22** 内容层一并排查，若仍独立存在再拆 bug

分层 Kraft 仍属父票 #18 未完成范围；抛弃式原型 `/prototype/post-token-layers/` 可在 #22 收尾时删除。

## 实现约束

- 实现时遵循 ui-styling / frontend-design（必要时 ui-ux-pro-max）中的成熟模式（焦点环、固定目录、文本标签、阅读栏层次等）。
- **不为本轮新引入** npm UI 组件库；继续 Astro + 站点 CSS 变量。对齐的是可访问与排版惯例，不是换皮到另一套组件框架。
- 选择器按博客真实 DOM（如 `.post-body`）映射 Kraft，不机械复制 Typora 的 `#write` / `.md-*`。

## 关系

- **部分取代** ADR-0001 中单篇页「768 卡片 / 704 净宽 / 页边目录 / 标题在卡片外」等条款，以及 ADR-0013 文末「单篇技术文章页标题区与 768 纸张卡片排版合同保持不变」。
- 归档、标签云壳、搜索面板、字体自托管等第二轮其余约定仍有效，除非被后续 ADR 修改。
- 首页/文章 visual 与 dist 合同中依赖旧 768 卡片断言的部分，落地时随实现一并更新。
