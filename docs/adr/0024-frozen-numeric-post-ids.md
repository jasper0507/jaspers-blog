# 技术文章网址使用冻结的数字稳定 ID

创建技术文章时作者只提供标题。系统分配一个创建时冻结的正整数稳定 ID，写入 frontmatter，公开网址为 `/posts/<ID>/`。另用 git 中的计数器文件只记录 next；删除文章留下空洞且不回收。创建失败（文件名冲突、号码文件写失败等）不占用号码，`next` 保持不变。文件名取创建时标题去掉非法字符后的快照，之后改标题不改文件名也不改网址。数字不表示发布时间，也不在页面上展示。

这取代 ADR-0015，以及 ADR-0005 中技术文章 ASCII 文件名与文章永久链接部分。公开投影用稳定 ID 生成 href，不再用 slug 指技术文章网址。按发布时间重排会破坏已分享链接；把号码只放在「文件名 ↔ 数字」登记表里，改文件名就会丢身份。
