# 视觉北星改为温暖克制的纸面长读

站点不再按实测同构 JacksBlog（废止 ADR-0001 / ADR-0013 中的视觉同构条款；信息架构、说说、自托管字体等其余条款仍有效）。北星是羊皮纸、珊瑚、暖灰、克制、适合长时间阅读；气质可参考 Claude，但不使用 Anthropic 商标、星标或产品壳，也不装 Tiempos / Copernicus / Styrene。

技术文章仍是文章页（标题、摘要、日期、阅读栏、目录、脚注、公式），不是聊天记录。正文只吸收 claude.ai **消息内部** Markdown 组件的节奏（标题层级、列表、表、引用、代码块的干净程度），用现有自托管衬线（Source Serif 4 + Noto Serif SC）和 IBM Plex 界面字映射，观感须与现行 Kraft 正文同类或更好。首页的「假」靠拿掉占位主视觉、加重作者声音与信息密度来治，不靠换框架。

第一期不改视觉合同：首页、单篇文章壳、阅读栏、行距与目录一律沿用本决策之前已验收的样子（ADR-0013 / ADR-0014，以仓库里当时的实现为准）。`/prototype/warmth/` 的 A/B/C 结构变体不进入生产。长期北星仍有效，但要动壳或首页须另开决策，不能夹在换栈里做。

第一期只允许技术文章正文里三类组件微调：引用、代码块、表格。对照改动前的验收图，几何（边距、行距、标题尺度）保持不动；可改的是边线色、圆角和表头线的干净程度。列表、行内代码、提示块、公式和目录不在这一期。

2026-08-17 修订：作者推翻上面两段的「已验收、不再重做」冻结合同——视觉一律以作者最新要求为准，不再以改动前的验收画面为对照合同；长期北星（温暖克制的纸面长读）与「换栈各票分开交付」不变，`/prototype/warmth/` 变体不进入生产的决定保留。后续每票的视觉验收以当票最新要求为准；动壳或首页不再需要另开决策，但仍不得夹在无关换栈票里顺手改。

2026-08-17 纸色裁定：作者对照 Claude 灵感包看过亮色纸面原型（现状 / parchment / oat / dusk）后维持现行 token（亮色 `#f5f2ea` / `#fbf9f4` / `#ded7c7`），暗色不动。抛弃式原型在 `prototype/paper-light`，不进生产。
