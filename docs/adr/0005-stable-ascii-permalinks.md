# 使用稳定的 ASCII 永久链接

界面与内容使用中文。文章永久链接为 `/posts/<slug>/`：文件名由作者分配简短、可读的小写 ASCII 语义词，不包含发布日期，也不根据中文标题自动转成拼音，以避免链接随标题或转写规则变化。归档与关于分别为 `/archives/`、`/about/`；站内搜索为导航放大镜打开的居中面板，不再使用独立 `/search/` 内容页（旧地址重定向至首页）。说说通过 `/shuoshuo/#<stable-id>` 分享。

迁移旧 Hexo Markdown 时，直接为文章分配符合上述规则的新永久链接；不保留旧的“日期 + 中文标题”路径，也不生成旧 URL 重定向。

标签为开放、可选的扁平主题词（见 ADR-0012）：frontmatter 可自由填写或省略，站点不维护封闭登记表。标签 URL 为 `/tags/<slug>/`，其中 slug 由标签名经稳定算法生成（与 GitHub 风格 slug 一致）；同名标签聚合到同一详情页。若两个不同标签名生成相同 slug，构建失败。无法生成有效 slug 的标签名亦使构建失败。

说说创建时按 `Asia/Shanghai` 生成 `YYYYMMDD-HHmmss` 格式的文件名和稳定 ID，例如 `20260731-213045.md` 对应 `/shuoshuo/#20260731-213045`。ID 创建后永久不变，不随正文或发布时间修订。
