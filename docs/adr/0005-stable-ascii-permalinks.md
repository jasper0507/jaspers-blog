# 使用稳定的 ASCII 永久链接

界面与内容使用中文，但公开 URL 使用小写 ASCII：文章为 `/posts/<slug>/`，标签为 `/tags/<slug>/`，归档、关于和搜索分别为 `/archives/`、`/about/`、`/search/`，说说通过 `/shuoshuo/#<stable-id>` 分享。文章文件名直接作为永久短名；标题可以是中文，但文件名由作者分配简短、可读的英文语义词，不包含发布日期，也不根据中文标题自动转成拼音，以避免链接随标题或转写规则变化。

迁移旧 Hexo Markdown 时，直接为文章分配符合上述规则的新永久链接；不保留旧的“日期 + 中文标题”路径，也不生成旧 URL 重定向。

标签名称在界面和文章 frontmatter 中保持中文，标签 URL 使用中央词表维护的固定 ASCII slug。构建遇到词表中未登记的标签时直接报错，不做自动拼音或隐式回退，以避免同一标签产生多个链接。

说说创建时按 `Asia/Shanghai` 生成 `YYYYMMDD-HHmmss` 格式的文件名和稳定 ID，例如 `20260731-213045.md` 对应 `/shuoshuo/#20260731-213045`。ID 创建后永久不变，不随正文或发布时间修订。
