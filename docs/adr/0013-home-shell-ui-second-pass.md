# 第二轮首页与外壳：主视觉图、内联搜索、克制列表

第二轮前端优化在保留 JacksBlog 节奏与 Claude 暖色克制风的前提下，调整首页与全站外壳。首页主视觉由三行禅语改为可配置图片：站点配置提供亮色 `src`、暗色 `srcDark`、共用 `width`/`height` 与 `alt`，作者改配置并替换资源后构建即可更新。首页「最近文章」「最近说说」各展示 1 条；最近文章为日期 + 标题 + 单行截断描述，不要大段摘要；「查看全部 (N)」使用半角括号并显示已发布总数（可为 0）。最近说说与说说列表统一为浅色纸面卡片，条目间用间距区分，不用分割线。分区上下分割线只调整长短以协调版式，不改现有字号与颜色体系。

主导航「文章」为下拉（归档、标签），「搜索」改为放大镜：点击或按 `/`（输入焦点不在可编辑控件时）打开居中搜索面板（遮罩 + 圆角卡片，Esc 关闭），不再使用独立搜索页；搜索范围仅技术文章，结果不展示二级标题等 sub-results。栏目列表页（归档、标签、说说等）去掉可见大标题、intro 与栏目顶部分割线，直接呈现内容；单篇技术文章页仍保留文章自身标题区。字体按角色自托管并对齐阅读主题：中文正文/标题/粗体为 Noto Serif SC 400/600/700，英文正文 Source Serif 4，界面 IBM Plex Sans 与 Noto Sans SC，代码 IBM Plex Mono，代码中文以 Sarasa Mono SC 为可选系统回退；用字重真文件与 unicode-range 分包降低伪粗与布局偏移。本决策部分撤回 ADR-0001 中「禅语文字主视觉」与「文章下拉为全部文章/标签/归档」的约定。
