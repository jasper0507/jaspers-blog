# 第二轮首页与外壳：主视觉图、内联搜索、克制列表

第二轮前端优化在保留 JacksBlog 节奏与 Claude 暖色克制风的前提下，调整首页与全站外壳。

## 首页（#12 已落地）

首页主视觉为可配置 **caption + 亮/暗双图**（`siteConfig.hero`：`caption`、`src`、`srcDark`、共用 `width`/`height`/`alt`）；默认 caption 为 `Talk is cheap. Show me the code.`，图为横版资源。桌面布局为 **双行两栏咬合**：第一行仅左栏 caption；第二行左图、右信息流，使信息流顶与图顶对齐；栏宽约 `1.65fr : 1fr`，中缝与主区上下间距对齐 JacksBlog 疏密。分区线为信息流栏 **近满宽顶边**（非短装饰段）；导航底线与页脚线落在 **内容壳**（`header-inner` / `footer-inner`）上，非整屏通栏。主题切换为 **全站右下悬浮圆钮**，不在顶栏。

首页「最近文章」「最近说说」各 1 条；字段节奏同构为 `YYYY.MM.DD` + 标题/正文首行 +（文章）单行截断描述；「查看全部 (N)」使用半角括号与已发布总数（可为 0），文章链归档、说说链说说列表；区头链接默认无下划线。首页说说不再渲染折叠 Markdown 摘要块。

本决策部分撤回 ADR-0001 中「禅语文字主视觉」与「文章下拉为全部文章/标签/归档」的约定。

## 归档（#13 已落地）

归档页 **打开即见内容**：无可见栏目大标题、intro 与顶部分割装饰；保留 document title 与 `sr-only` 页面名「归档」。已发布技术文章按年分组，以 **卡片时间轴** 展示：竖线与圆点共用同一横坐标并对齐穿过；每条卡片含 `YYYY-MM-DD` 日期、标题链到 `/posts/:slug/`、以及可点标签（复用单篇页标签组件；无标签不渲染该行）；不展示分类路径与摘要。草稿不出现。验收落在 dist 合同与 visual（含轴线–圆点对齐）上。

## 标签（#14 已落地）

标签索引 **打开即见标签云**：无可见栏目大标题与 intro；保留 document title 与 `sr-only` 页面名「标签」。云条目为标签名 + 数字计数，字号仅随频次做轻微缩放（主要靠计数传达权重）。点击进入该标签下的技术文章列表：同样无栏目壳；条目为 `YYYY-MM-DD` 日期 + 标题链到 `/posts/:slug/`，不展示摘要。仅聚合已发布技术文章；无任何标签时展示「暂无标签」空态。说说不参与标签。验收落在 dist 合同与 visual 上。

## 仍属第二轮、由后续工单落地

主导航「文章」为下拉（归档、标签）— **#11 已落地**。「搜索」改为放大镜：点击或按 `/`（输入焦点不在可编辑控件时）打开居中搜索面板，不再使用独立搜索页；搜索范围仅技术文章，结果不展示 sub-results（#16）。栏目列表页中说说、关于等仍待去可见大标题 / intro / 顶部分割线（#15 等）；单篇技术文章页仍保留文章自身标题区。说说列表与首页预览的 **浅色纸面卡片化** 由 #15 等工单完成。字体按角色自托管并对齐阅读主题：中文正文/标题/粗体为 Noto Serif SC 400/600/700，英文正文 Source Serif 4，界面 IBM Plex Sans 与 Noto Sans SC，代码 IBM Plex Mono，代码中文以 Sarasa Mono SC 为可选系统回退（#17）。
