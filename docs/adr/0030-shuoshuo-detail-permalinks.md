# 说说使用独立详情页永久链接

每条说说以稳定 ID 形成 `/shuoshuo/<稳定ID>/` 独立静态详情页，所有站内链接、RSS、canonical 与链接预览全面使用该网址；旧 `/shuoshuo/#<稳定ID>` 锚点不保留兼容。时间流继续存在，详情页进入 sitemap、保持不进入 Pagefind，并以系统生成的“说说 · 日期时间”作为页面与无障碍标题，不增加作者标题。

说说摘要通过 Markdown AST 从完整正文自动生成，是最多 80 个用户感知字符的纯文本投影：首页、RSS、链接预览和长说说折叠预览共用同一结果，但正文始终是内容事实来源。投影只收集普通文本节点和图片节点，不为代码、公式或原生 HTML 增加专门规则；链接文字自然作为普通文本保留，URL 删除，图片 alt 不作为正文，只以 `[1 Image]` 或 `[N Images]` 计数。图片标记与正文共同占用上限，连续空白和换行合并；截断使用 `Intl.Segmenter("zh-CN", { granularity: "grapheme" })`，只有文字确实被截断时才添加计入上限的省略号。既没有可投影文字也没有图片的说说使构建失败，因此只有代码、公式或原生 HTML 的说说同样无效；这些写法仍可随普通正文渲染，只是不扩张摘要合同。时间流中正文被截断或包含图片时默认折叠并隐藏图片，详情页始终展示完整正文。

独立网址避免未来分页、归档或按年份拆分时间流时破坏正式链接；代价是增加静态页面数量，并主动放弃已分享的旧锚点。本决定取代 ADR-0003、ADR-0005 与 ADR-0018 中的说说详情页、永久链接和摘要规则。
