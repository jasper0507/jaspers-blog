# 发布前本机校验写作规则，文章摘要可空

创作者 `publish` 在提交和推送前校验内容仓写作规则（头信息、正文、稳定 ID、标签网址），失败则中文报错且不提交、不推送。命令仍以 git push 为终点，不调用 GitHub CLI，也不在本机构建网站（ADR-0034、ADR-0035）。公式渲染和整站构建仍由远端发布任务兜底。待提交列表只说明新文件、已修改或已删除，不输出 git 状态码。

技术文章 `description` 仍必填，但允许空字符串。列表和文章页不渲染空摘要；页面元信息和 RSS 回退到站点描述。正文仍不能为空。
