# 将写作内容迁入独立私有仓库

技术文章、说说、「关于我」和技术文章号码计数器由私有内容仓负责；页面、博客设置、首页主视觉、
字体、构建系统和实际工具实现由公开源码仓负责。这个边界让创作者只处理 Markdown 和轻量命令，
同时让公开源码在没有私有凭据时用示例内容完成开发与验收。

内容仓从切换时的文件快照建立新历史，保留所有稳定 ID 与计数器；源码仓不改写旧历史，因此迁移前
已经公开的内容仍可读取。内容仓使用源码仓 GitHub Release 中固定版本的零依赖工具，网站与工具
共用源码仓维护的领域规则，不在内容仓复制第二套实现。

内容推送和源码合并统一触发私有内容仓的发布工作流。流程固定两仓准确提交，校验并构建后用
Wrangler 上传原 Cloudflare Pages 项目；该项目的 Git 自动部署保持关闭。失败保留内容提交和上一
个成功站点，无改动重试不创建空提交，并用基本串行控制避免旧结果覆盖新版本。

本决定取代 ADR-0004 的单仓内容直推规则、ADR-0029 的内容仓公开规则，以及 ADR-0007 和
ADR-0018 中将 `src/content/` 作为正式写作位置的部分。源码变更继续通过 PR，并等待 `verify` 与
`browser-smoke` 成功后合并。
