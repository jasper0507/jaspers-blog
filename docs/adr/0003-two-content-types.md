# 内容只分为技术文章和说说

网站只定义技术文章和说说两种内容类型：技术文章承载有标题、摘要和标签的长内容，网址为 `/posts/<稳定ID>/`（ADR-0024）；说说承载无标题的短内容及可选照片。“照片配几行文字”仍是说说，不建立照片内容类型或照片频道，以避免重复的发布流程、路由和列表页面。说说不生成独立详情页，只在 `/shuoshuo/` 时间流中展示，通过稳定锚点链接分享，长内容原地展开。标签和归档只收录技术文章；说说进入首页摘要和统一 RSS，不进入站内搜索（站内搜索仅技术文章，见 ADR-0013）。

说说在可见页面上始终无标题；RSS、链接预览和无障碍名称由系统按发布时间生成“说说 · 日期时间”标签，作者无需维护该字段。
