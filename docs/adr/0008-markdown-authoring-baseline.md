# 限定 Markdown 写作能力

技术文章与说说使用普通 Markdown，不要求作者编写组件代码。默认支持 KaTeX 数学公式、GFM 表格/任务列表/删除线/自动链接、Shiki 代码高亮及文件名/行高亮/diff 标记、提示块、标题锚点、自动文章目录和原生 `<details>` 折叠内容。Shiki 继续负责语法识别和上述附加能力，但亮暗两套 token 颜色映射到 Kraft Paper 色板，使代码块背景、边框与语法颜色形成同一视觉系统。

Kraft Paper 未定义提示块和 `<details>`，网站按其视觉语言作克制扩展：提示块统一使用暖色浅底、细左边线和小号类型标签，不同语义只改变边线与标签颜色，不使用整块高饱和背景；`<details>` 使用同色系细边框，不表现为厚重卡片。

第一版不引入 Mermaid 或 MDX：当前内容不依赖它们，Mermaid 会增加浏览器端脚本，MDX 会让内容与组件代码耦合；出现实际内容需求时再单独加入。
