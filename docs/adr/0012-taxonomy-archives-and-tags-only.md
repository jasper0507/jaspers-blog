# 技术文章只按归档与标签组织，不设分类

第二轮信息架构曾考虑 Hexo 式「归档 / 分类 / 标签」，并一度要求层级分类与 frontmatter 高自定义；随后明确取消分类功能。技术文章的公开浏览切片只保留两种：归档（按时间）与标签（扁平主题词）。标签可选、可多个、由作者在 frontmatter 中自由填写，站点构建时自动聚合，不维护封闭登记表。导航「文章」下拉仅含归档与标签；完整文章列表由归档页承担，不再提供与归档并行的「全部文章」列表页，既有 `/posts/` 列表路由重定向至归档。单篇技术文章 URL 为 `/posts/<稳定ID>/`（ADR-0024）。说说不参与标签与归档。

归档页 UI（按年卡片时间轴、无栏目壳、条目日期 + 标题 + 可点标签）见 ADR-0013 与 #13。标签索引页 UI（中性纸面 chip 云、同字号、计数角标、无栏目壳、详情日期 + 标题列表）见 ADR-0013 与 #14。单篇与归档上挂在技术文章上的标签为弱化 `#tag` 文本链（ADR-0014 / #21）；`/tags/` 云仍为 chip。无标签时不渲染该行。
